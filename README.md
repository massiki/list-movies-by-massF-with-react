# Catatan Penting

Jika anda mengcloning project ini, berikut adalah file yang harus anda siapkan 

buatlah file dengan nama 
### `.env.local`

berikut adalah isi file dari .env.local

```env
REACT_APP_BASE_URL=
REACT_APP_PATH_URL=
REACT_APP_API_KEY=
REACT_APP_API_TOKEN=
```

API dari TMDB, berikut adalah link websitenya
https://www.themoviedb.org/
